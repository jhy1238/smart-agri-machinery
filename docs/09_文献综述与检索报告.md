### 1.4 去重与相关性过滤

**去重规则**（两级）：

1. **DOI 规范化去重**：统一小写、剥离 `https://doi.org/` 前缀后作为唯一键；
2. **标题归一化兜底**：对无 DOI 的记录，取标题去除标点、空格、大小写后归一化比对。

跨库同一条文献会被合并，并保留 `source_db` 字段记录它出现在哪些数据库中（如 `OpenAlex+PubMed+EuropePMC`），不重复计入。

**相关性过滤**：由于 Crossref/PubMed 的全文检索会返回模糊匹配结果，对所有记录按"农业 × 机械 × 智能"三组词典打分：

- 农业词典：agricultur\*、farm\*、crop、orchard、tractor、harvester、irrigation、fertiliz\*、weed、农业、农机、作物、灌溉、施肥、果园、大田……
- 机械词典：machin\*、robot、vehicle、implement、UAV、autonomous、navigation、GNSS、RTK、LiDAR、ISOBUS、机械、装备、无人、导航……
- 智能词典：deep learning、CNN、computer vision、reinforcement learning、path planning、digital twin、IoT、sensor fusion、深度学习、路径规划、数字孪生……

命中标题的词权重为正文的 3 倍，最终得分需同时满足"含农业词"与"含机械或智能词"且总分 ≥ 6 才保留。

**过滤效果**：4491 条去重记录 → **1958 条高相关记录**（保留率 43.6%），其中 1867 条含 DOI、1147 条含开放获取全文链接。

## 3 研究现状综述

### 3.1 总体图景：从精准农业到智能农机

过去十年，农业装备的智能化沿着"**精准农业（Precision Agriculture）→ 智慧农业（Smart Farming）→ 自主农机（Autonomous Machinery）**"的路径演进。

Wolfert 等（2017）在 *Big Data in Smart Farming* 中最早系统性地提出智慧农业的数据驱动范式，指出农场将演化为"网络-物理管理循环"（Cyber-Physical Management Cycle），其核心矛盾在于**数据的所有权与互操作性**，而非单纯的技术能力 [L1838]。这一判断至今仍是农机数据平台设计的根本约束。

Kamilaris 与 Prenafeta-Boldú（2018）在 *Deep learning in agriculture: A survey* 中梳理了 40 余项深度学习在农业中的应用，指出当时绝大多数工作集中于**分类任务**（作物/杂草/病害识别），而序列决策、控制类任务严重不足 [L1786]。该文被引超过 5000 次，是领域内引用量最高的综述之一。Liakos 等（2018）的 *Machine Learning in Agriculture: A Review* 从作物管理、畜牧、水土管理等维度做了更宽的铺陈，但同时坦承**从"感知准确率"到"田间作业收益"之间缺少闭环验证** [L1787]。

到 2020 年前后，综述的视角明显从"算法能做什么"转向"系统如何落地"。Sharma 等（2020）与 Sáiz-Rubio、Rovira-Más（2020）分别从精准农业技术栈与 Agriculture 5.0 的角度，把讨论推进到**农机-农艺-数据的一体化** [L1548][L1549]。Jha 等（2019）则明确把"自动化农业"拆解为感知、决策、执行三层，并指出**执行层的机电接口标准化**是规模化的真正瓶颈 [L1687]。Karunathilake 等（2023）在 *The Path to Smart Farming* 中进一步给出技术成熟度分层，认为**导航与变量作业已进入商业成熟期，而全自主作业仍处于示范阶段** [L0970]。

> **对本项目的启示**：现有文献在"单点算法指标"上已相当充分，真正的空白在于**把感知—规划—控制—平台串成可复现的闭环，并给出可量化的一致性验证**。本项目 `src/` 中的端到端原型正对应这一空白。

### 3.2 感知与定位

**GNSS/RTK 与导航感知**。RTK 差分定位把水平精度从米级提升到厘米级，是农机自动导航的前提。Thanpattranon 等（2016）在 *Biosystems Engineering* 上给出了果园环境下拖拉机-拖车组合的激光雷达导航方案，用激光测距直接估计拖车相对位姿，回避了 GNSS 在树冠遮挡下不可靠的问题 [L1895]。该类工作揭示了**单一传感器在农田环境中必然存在不可用区间**，多源融合是刚需。

**视觉与杂草识别**。Wang 等（2019）的综述系统比较了基于地面机器视觉的杂草检测方法，明确了三个长期难点：**类间相似（作物与杂草早期形态接近）、类内差异（光照/生长期）、以及实时性约束**；并指出单纯追求分类精度而忽视**作业速度下的推理延迟**是常见误区 [L1691]。这直接支持本项目在视觉链路中同时报告精度（F1）与**单帧时延**的做法。

**遥感与无人机**。Adão 等（2017）综述了无人机载高光谱成像的传感器、数据处理与农林应用，给出了完整的"成像—辐射校正—特征提取—建模"管线 [L1839]。Sishodia 等（2020）从遥感视角梳理了精准农业的作物监测、土壤制图与变量作业分区方法 [L1546]。Fei 等（2022）则用无人机多源数据融合 + 机器学习做小麦产量预测，验证了**多源特征融合优于单一传感器** [L1187]。

**病虫害识别**。Picón 等（2018）的工作尤为值得注意：他们明确针对"**野外移动设备拍摄**"这一真实工况，而非实验室受控图像，用深度卷积网络做作物病害分类 [L1789]。这类"面向真实退化条件"的研究，比在干净数据集上刷高准确率更有工程价值。

### 3.3 决策与规划

**产量预测与农情分析**。Chlingaryan 等（2018）综述了机器学习在作物产量预测与氮素状态估计中的应用，指出**输入特征的物理可解释性**决定了模型能否被农艺人员接受 [L1788]。

**变量作业**。变量施肥/喷药依赖处方图，其本质是**把稀疏的点采样与遥感栅格外推为作业机具可执行的连续处方**。文献普遍承认，处方图的空间分辨率与机具响应带宽不匹配是精度损失的主要来源。

**全覆盖路径规划**。农机作业路径规划不同于一般的移动机器人路径规划：约束来自**机具幅宽、最小转弯半径、地头空间、以及必须达到的覆盖率**。文献中主流做法是牛耕式（boustrophedon）往返 + 地头转弯优化，评价指标为覆盖率、重叠率、非作业里程占比。

**机群调度**。随着农机服务组织规模扩大，多机协同调度成为热点，目标函数通常同时包含作业完成时间、空驶里程、机具-地块匹配与时间窗约束，求解方法从构造式贪心到遗传算法、禁忌搜索不等。

> **本项目对应**：`src/planning/coverage_path.mjs`（牛耕式 + Π/Ω 地头转弯 + 重叠率建模）与 `src/planning/dispatch.mjs`（构造式贪心 + 2-opt 改进，并与朴素分配做基线对比）。

### 3.4 控制与执行

**路径跟踪**。纯跟踪（Pure Pursuit）因其实现简单、对速度变化鲁棒，仍是商业农机自动导航的主流控制器；其关键参数是**前视距离**，需随速度与曲率自适应。

**拖拉机-机具协同**。Shojaei（2021）在 *European Journal of Control* 上研究了自主拖拉机-挂车与联合收割机的智能协同控制，处理了**强耦合非线性与作业时序约束**下的编队问题 [L1450]。

**电气化与总线标准化**。Mocera 等（2023）综述了农机电气化的趋势与前景，指出**电气化与智能化是同一场变革的两面**：电驱动天然具备精确的转矩/转速控制能力，为变量作业与自主作业提供了执行层基础 [L1016]。ISOBUS（ISO 11783）则解决了不同厂商机具与拖拉机之间的通信互操作问题，使"一个终端控制多种机具"成为可能。

> **本项目对应**：`src/control/pure_pursuit.mjs`（自适应前视距离 + 曲率限速 + 闭环跟踪误差评估）与 `src/cloud/telemetry.mjs`（J1939/ISOBUS 报文编解码与故障诊断）。

### 3.5 平台与数据

Ayaz 等（2019）在 *IEEE Access* 上给出 IoT 智慧农业的系统性框架，覆盖土壤、气象、灌溉、牲畜等多类节点的网络架构与通信协议选择 [L1684]。Verdouw 等（2021）的 *Digital twins in smart farming* 是数字孪生在农业领域的高被引代表作，提出了**以"可执行的农场模型"替代静态记录**的数字孪生路径 [L1378]。

近年"云-边-端协同"成为主流架构：边缘侧完成实时感知与控制，云端负责长周期建模、多机协同与运维。这一分工直接决定了**数据模型与上行带宽预算**，也是本项目 `src/cloud/telemetry.mjs` 中"边缘聚合—批量上行—云端检测"链路的设计依据。

### 3.6 农业机器人

Fountas 等（2020）综述了田间作业机器人，强调**田间机器人的瓶颈不在机械臂或算法，而在作业环境的结构化程度与安全性验证** [L1560]。Oliveira 等（2021）的 *Advances in Agriculture Robotics* 给出了更完整的技术分类与挑战清单 [L1385]。

采摘机器人方面，Tang 等（2020）系统综述了基于视觉的水果采摘机器人识别与定位方法，梳理了"检测 → 分割 → 三维定位 → 抓取规划"的完整链条 [L1555]；Williams 等（2019）则在 *Biosystems Engineering* 上报告了猕猴桃采摘机器人（机器视觉 + CNN + 机械臂）的实机系统 [L1699]，是少数给出端到端实测数据的工作。

### 3.7 中国研究现状（基于 CNKI 749 条）

CNKI 采集的 749 条中文文献呈现出与英文文献明显不同的分布特征：

**来源高度集中于行业期刊与高校**。发文量前列的来源包括《南方农机》（61 篇）、《河北农机》（48 篇）、《农机使用与维修》（30 篇）、《农业机械学报》（21 篇）、《农机化研究》（18 篇）、《中国农机化学报》（17 篇）、《中国农机装备》（17 篇）、《农业机械》（15 篇）；高校来源以江苏大学、华南农业大学、山东理工大学、黑龙江八一农垦大学、西北农林科技大学为主（多为学位论文）。

**选题偏应用与政策**。高频主题为"农业机械智能化改造与升级的关键技术""智能化技术在农业机械电气控制系统中的应用""农业机械智能化发展的现存问题与应对策略""电子信息赋能下的农机智能化升级路径"等，**以技术综述、现状分析与对策建议为主**，涉及具体算法创新与实机验证的比例较低。

**代际差距**。与英文文献相比，中文文献在"智能农机总体与综述"这一主题上数量可观，但在**全覆盖路径规划、机群调度、ISOBUS 总线控制**等偏底层与系统性的方向上数量明显偏少（分别仅 70、149、125 条，且多为综述性提及而非原创方法）。

> **结论**：中文研究在**产业落地、政策与推广**侧积累丰富，在**算法原创与系统级闭环验证**侧存在明显缺口。这构成了本项目选题的现实依据，也是本项目同时交付"工程方案 + 可运行原型 + 国际文献库"的原因。

## 5 全文获取与合规说明

### 5.1 已获取的全文

本地 `literature/pdf/` 共 **673 篇**、`literature/pdf_extra/` 另有 **29 篇**跨主题扩展全文，合计 **702 篇 / 3.38 GB**，全部为**开放获取（Open Access）**文献，通过合法公开渠道获取：开放获取期刊官网、arXiv、PubMed Central、机构知识库及中文开放获取期刊。

其中 MDPI 系列期刊（*Sensors*、*Agriculture*、*Agronomy*、*Remote Sensing*、*Energies* 等）因站点采用 Akamai JS 挑战，普通 HTTP 请求无法获取，本项目改用**真实浏览器会话**下载（先访问文章页取得风控 Cookie，再访问 PDF 端点捕获下载流），该批次下载成功率 **100%（270/270）**。

下载过程做了三重校验：

1. 内容校验：文件头必须为 `%PDF`，且能解析出页面对象；
2. 哈希去重：对文件内容计算 SHA-256，同一文献的不同链接不会重复落盘；
3. DOI 去重：同一 DOI 只保留一份。

### 5.2 订阅数据库（CNKI / 万方）的全文

CNKI 的**元数据检索是公开的**，本项目已完整采集 749 条真实题录（题名、作者、来源、发表日期、文献类型、被引），并生成 `literature/CNKI_INDEX.md`，每条都带可直接跳转知网的链接。

但**全文下载受机构订阅授权限制**，且知网对自动化访问设有安全验证（滑块验证码）。本项目**不绕过任何访问控制与反爬机制**，因此对中文订阅文献采取以下合规路径：

1. 检索元数据已本地化（`literature/CNKI_INDEX.md`），可直接按题名定位；
2. 学校已提供 SSL VPN（`https://vpn.cqjtu.edu.cn`）用于校外访问，本项目已实现其登录流程（见 `scripts/vpn_login.mjs`）供参考；
3. 建议在校园网或机构 VPN 环境下，用机构账号在知网检索并逐篇下载到 `literature/pdf/`。

> **版权提示**：下载的文献仅供个人学习与研究使用，请勿二次分发或用于商业用途。

## 6 文献库结构

```
literature/
├── INDEX.md                  # 文献库总索引（概览统计 + 按主题分组的全文清单）
├── CNKI_INDEX.md             # CNKI 749 条中文题录索引
├── pdf/                      # 已下载的开放获取全文 PDF
├── pdf_extra/                # 跨主题/泛农业与智能技术的扩展全文
└── metadata/
    ├── records.json          # 主记录集（1958 条，含摘要、DOI、全文链接、主题标签）
    ├── records_all.json      # 过滤前的全量记录（4491 条）
    ├── records.csv           # 表格版（可用 Excel 打开）
    ├── references.bib        # BibTeX，可直接导入 Zotero / EndNote / LaTeX
    ├── cnki_records.json     # CNKI 中文题录
    ├── download_manifest.json# 下载清单（文件名、SHA-256、页数、来源链接）
    ├── download_report.json  # 下载统计报告
    ├── doi_verification.json # DOI 真实性抽样核验结果
    └── digest.json           # 统计摘要
```

**导入文献管理软件**：直接导入 `references.bib`；若需带附件，可用 Zotero 的"从文件夹导入"，指向 `literature/pdf/`。
